What dynamic_cast does at runtime
✓ dynamic_cast<Derived*>(bp) — succeeds
Follows vptr → reads type_info → "Derived" matches target → returns the same address as bp.
✗ dynamic_cast<Other*>(bp) — fails safely
Follows vptr → reads type_info → "Derived" is not "Other" and not in its hierarchy → returns nullptr. No crash, no undefined behavior.
Why virtual ~Base() is required: No virtual function → compiler emits no vtable → no vptr in the object → no RTTI pointer → dynamic_cast has nothing to follow and won't compile.
